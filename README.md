# 🤖 AI Job Application Assistant

> An AI-powered job search and career assistant that helps candidates discover relevant opportunities, analyze job matches, and prepare better applications.

## 🚀 Live Demo

👉 **[Launch AI Job Seeker](https://job-application-assistant-8cbdpemhzlgwjcqlojagww.streamlit.app/)**

## ✨ Features

- 🔎 AI-powered job search
- 🎯 Job-to-profile matching
- 📊 Job match scoring
- 💼 GET / Graduate Engineer / Trainee opportunities
- 🏭 Metallurgy, Materials, Quality, Production & Process roles
- 📈 Data Analyst opportunities
- 🏦 Banking Operations & Analyst opportunities
- 📄 Resume-based job recommendations
- 🤖 AI-assisted career support

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Sentence Transformers
- REST APIs
- GitHub
